PHPStan's levels as analyse presets: `phpstan/level_<n>` runs what `phpstan analyse --level <n>` runs with PHPStan's default parameters. Turn one on in `pun.toml`:

```toml
[analyse]
preset = "phpstan/level_5"
```

`phpstan/level_max` is `phpstan/level_10`. PHPStan's opt-in checks, phpstan-strict-rules and phpstan-deprecation-rules are not part of any level: turn their rules on in `[analyse.rules]`. Larastan's default rules run when the `laravel` [extension](/docs/configuration/pun-toml#extensions) is on. PHPStan checks that are lint rules in Pun are turned on in `[lint]` too. The few that are format rules (such as `format/whitespace/encoding`) are not: turn them on in `[format.rules]`. Planned rules do not run. [Presets and sets](/docs/configuration/presets#phpstan-level-presets) explains the rest.
