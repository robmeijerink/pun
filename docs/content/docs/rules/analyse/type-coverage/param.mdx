In the [`analyse-basic`](/docs/rules/presets/analyse-basic) preset and every stricter one. Report only.

## What it does

Each param declaration without a native type, while fewer than `min` percent (default 99) of the project's param declarations have one; `measure = true` reports the coverage instead.

## Configuration

```toml title="pun.toml"
[analyse.rules]
"type-coverage/param" = "on"
```
